NiYien 使用帮助

1. 添加素材

从相册、文件或文件夹选择视频。请使用支持记录陀螺仪数据的相机；普通手机视频可能没有陀螺仪稳定所需的运动数据。

2. 按需添加外置陀螺仪数据

在“添加素材”中切换到“外置陀螺仪”，选择对应的运动数据文件。批量处理前检查视频与陀螺仪的时间是否正确。

3. 设置稳定和镜头参数

设置会应用到列表中的全部视频。请确认镜头和设备安装方向正确；部分相机需要单独的镜头配置。

4. 预览与导出

打开视频可以比较“原始”与“稳定后”。“导出稳定视频”生成可播放的视频；“稳定（插件用）”生成用于兼容桌面编辑器/插件的 .gyroflow 工程，不等于完成视频导出。

5. 取回结果

选择能在“文件”中访问的输出文件夹。处理完成后打开任务查看结果，iOS 可使用“分享／存储到文件”。长时间处理请保持 NiYien 在前台，并留意可用存储空间。

没有可用陀螺仪数据、运动数据未同步、格式不支持或镜头信息错误时，请按提示修正对应输入后重试。取消任务不会删除原视频。

6. 体验合成示例

在“设置 → 应用 → 帮助与支持”点击“体验内置示例”。内置的 6 秒合成视频带有配套运动数据和镜头模型，可用于预览“原始／稳定后”、导出视频，以及通过“分享／存储到文件”取回结果。示例用于演示流程，不代表真实相机画质或设备性能。

也可下载示例文件与审核操作说明。无需账号；下载包包含原始视频、运动数据、工程文件和生成源码。

当前 iOS 版本支持从文件导入外置陀螺仪数据，不提供 NiYien A1 实时 USB 设备通道或固件升级通道。

支持

请发邮件至 support@niyien.com，或使用“设置 → 应用 → 反馈”。应用内提交会自动附带当前可用的诊断资料；也可直接发邮件，不附加应用诊断资料。排查时可提供应用版本、设备型号和复现步骤，请勿发送密码或私人视频。兼容说明和源代码：https://github.com/NiYien/gyroflow。

NiYien — Help and support

1. Add media

Choose videos from Photos, Files or a folder. Use a supported camera with recorded gyroscope data. Ordinary phone videos may not contain the motion data required for gyro stabilization.

2. Add external gyroscope data if needed

In Add media, choose External gyroscope and select the matching motion file. Check the video and gyroscope timestamps before starting a batch.

3. Set stabilization and lens parameters

Settings apply to all videos in the list. Use the correct lens and mounting orientation. A separate lens file may be needed for your camera.

4. Preview and export

Open a video to compare Original and Stabilized. Export stabilized video produces a playable video. Stabilize (for plugins) prepares a .gyroflow project for a compatible desktop editor/plugin; it does not itself produce a finished video.

5. Retrieve the output

Choose an output folder you can access in Files. Open a completed task to view its result or use Share / Save to Files on iOS. Keep NiYien in the foreground during long processing and check available storage.

If a video has no usable gyroscope data, no synchronized motion, an unsupported format or incorrect lens information, fix the corresponding input before retrying. Cancelling a task does not delete your source video.

6. Try the generated sample

In Settings → App → Help and support, tap Try a generated demo. The bundled six-second synthetic clip includes matching motion data and a lens model. Compare Original / Stabilized, export a video, then open the completed task and use Share / Save to Files. The sample demonstrates the workflow; it is not a camera-quality or performance benchmark.

You can also download the sample files and review instructions. No account is required. The archive contains the source video, motion data, project file and generator source.

The current iOS version imports external gyroscope files but does not provide the NiYien A1 real-time USB device channel or firmware update channel.

Support

Email support@niyien.com, or use Settings → App → Feedback. In-app submission automatically includes available diagnostic information for troubleshooting; email is an alternative that does not attach app diagnostics. Include the app version, device model and steps to reproduce the issue when useful. Do not send passwords or private video files. Project compatibility and source code: https://github.com/NiYien/gyroflow.
